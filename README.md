# Suranga Gems

A premium, mobile-first brand website for **Suranga Gems**, presenting the founder, gemstone expertise, sourcing story and Sri Lanka–Madagascar presence through a refined luxury web experience.

🔗 **Repository:** https://github.com/linuka7/suranga-gems

## About the project

Suranga Gems is a portfolio/client-style website created for a gemstone business with a focus on **trust, heritage, sourcing and premium visual presentation** rather than e-commerce.

The site is designed to communicate the brand and its story to gemstone buyers and business contacts across Sri Lanka and Madagascar.

## Goals

- Establish a premium digital presence for a gemstone brand
- Present the founder and business story clearly
- Highlight Sri Lanka and Madagascar as part of the brand's sourcing identity
- Make the experience feel high-end while remaining fast and easy to navigate
- Prioritize mobile usability for visitors who primarily browse on phones
- Provide clear navigation to the brand story, collections, sourcing and contact sections

## Key features

- Premium luxury-oriented visual design
- Mobile-first responsive layout
- Responsive navigation with mobile menu
- Hero presentation with strong brand positioning
- Founder / brand story section
- Gemstone collections presentation
- Sourcing and business information
- Gallery section
- Contact section
- Smooth section-based navigation
- Responsive typography and spacing
- Reusable React components
- Icon-based UI using Lucide React and React Icons
- Contact form integration through Formspree

## Design direction

The visual direction intentionally combines **luxury gemstone branding with restrained modern web design**.

The interface emphasizes:

- Elegant typography
- Generous whitespace
- Refined spacing
- Subtle motion and interaction
- Strong mobile layouts
- Minimal, premium navigation
- Brand-focused storytelling instead of heavy UI

## Running locally

### Prerequisites

- Node.js
- npm
- Git

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Vite will provide the local development URL in the terminal.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## Deployment

The project is built as a static Vite application and can be deployed to platforms such as Vercel, Netlify or Cloudflare Pages.

The live deployment is intentionally kept separate from the repository documentation so the README does not depend on an expiring demo URL.
